## 已实现分析视角的角色

目前以下4个角色在 `src/agents/domains/haip/core/roles.py` 中完成 `RoleDef` 定义及 `view_patient_as_*()` 诊疗数据分析视角：

| 角色 | 分析视角 | 关注领域 |
|------|----------|----------|
| **麻醉科医生** | `view_patient_as_anesthesiologist()` | 气道评估、ASA分级、心脏风险(RCRI)、抗凝管理、容量状态、疼痛控制、凝血功能、药物过敏、PONV、困难气道预案 |
| **主治医生** | `view_patient_as_attending()` | 诊断确认、手术指征、保守vs手术、合并症、MDT需求、康复计划、随访、用药方案、患者教育 |
| **药剂师** | `view_patient_as_pharmacist()` | 营养风险筛查(NRS2002)、再喂养综合征评估、电解质监测、风险规则引擎、配伍禁忌检查、药品信息 |
| **护士长** | `view_patient_as_head_nurse()` | 围术期护理方案(4阶段21项)、DVT预防(IPC/GCS/踝泵)、体位管理、Braden压疮、疼痛护理、跌倒预防、出院指导 |

其余角色（康复治疗师等）视角在规划中，待扩展。

## 引用方式

HAIP各Agent可通过以下方式引用本角色体系：

```python
# 加载skill中定义的角色数据
# 科室sub-agent可通过角色名查询岗位职责、所属科室、英文标识
```

角色英文标识作为跨系统统一标识，在 `organization.py`、`roles.py`、`togaf.py`、`togaf_data.py`、`template.py` 中保持一致。
