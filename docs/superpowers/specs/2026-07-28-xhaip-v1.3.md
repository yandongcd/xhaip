# xhaip v1.3 — 运行时质量 + Per-Agent 精简

> 设计文档 | 2026-07-28 | 基线: tech-debt-audit 18/22 fix + 五层质量模型

## 1. 愿景

v1.2 PROD-READY 的基底上，完成两个关键跃迁：

1. **运行时质量自动化** (Stage 9 + 11) — 338 个 handler 被 498 位真实患者驱动的 A2A 调用逐一验证，Guard 有效性持续审计
2. **Per-agent 部署精简** — 每个 Docker 容器仅加载自己需要的 YAML（1-3 个 vs 当前 58 个），启动时间降 90%，内存降 90%

两者互补：Stage 9 的批量 A2A 调用天然适合 per-agent 分离后的独立容器执行。

#### C: Per-agent 精简加载

**修改文件：**

`agent/__init__.py`:
```python
def load_from_dir(dir_path: str, agent_filter: str = "") -> int:
    if agent_filter:
        return _load_single_agent(dir_path, agent_filter)
    return _load_all_agents(dir_path)

def _load_single_agent(dir_path: str, agent_name: str) -> int:
    # 加载 agent + 其 depends_on 链（BFS）
    loaded: set[str] = set()
    queue = [agent_name]
    count = 0
    while queue:
        name = queue.pop(0)
        if name in loaded:
            continue
        # load YAML, register agent
        loaded.add(name)
        count += 1
        for dep in agent.depends_on:
            if dep.agent not in loaded:
                queue.append(dep.agent)
    return count
```

`web_server.py`:
```python
agent_filter = os.environ.get("XHAIP_AGENT_NAME", "")
load_from_dir(str(YAML_DIR), agent_filter=agent_filter)
```

`docker/Dockerfile.agent`:
```dockerfile
ENV XHAIP_AGENT_NAME=$AGENT_NAME
```

#### B: YAML 废弃定义清理

`agent/__init__.py` 中 `load_from_dir()` 和 `list_all()` 跳过：
- 文件名包含 `.deprecated` 的 YAML
- 文件名包含 `.internal` 的 YAML

`list_all()` 返回活跃 agent 数量（58 → 从 74 YAML 中过滤后计数）。

### 3.2 Week 2 — Self-Harness Stage 9 + 11

#### Stage 9: Runtime A2A

已有设计文档 `docs/superpowers/specs/2026-07-26-self-harness-v4-design.md` 的第 3 节。关键参数：
- 338 handler 函数（从 agent tools 的 handler 字段提取）
- 每个 handler 用 3 位 compatible 患者调用
- 4 路 ThreadPoolExecutor 并发
- 10s timeout per call
- 输出：`runtime_results` 表 (pass/fail/timeout/error)

#### Stage 11: Guard Audit

在 Stage 9 的基础上，对高风险 handler 的输出重新执行 Guard 验证：
- 统计 Guard silent-bypass（`except Exception: pass` 模式）
- 统计 miss rate（Guard 未检出已知风险）
- 输出：`guard_metrics` 表
