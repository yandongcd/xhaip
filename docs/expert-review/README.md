# 多医院多学科专家 10 轮迭代评估

## 方法论：改良德尔菲法 (Modified Delphi)

对 82 份 xHAIP 需求设计方案，从诊疗规范、行业共识、临床指南、法规标准四个维度，进行多学科、多医院的独立专家评审与交叉印证。

## 评估维度

每条遗漏发现包含：

| 字段 | 说明 |
|------|------|
| 文档编号 | A1-A82 |
| 相关科室 | 所属专科 |
| 遗漏类型 | 指南 / 共识 / 规范 / 标准 / 评分量表 / 分类体系 / 法规 / 教材 |
| 遗漏项名称 | 含年份与版本号 |
| 遗漏等级 | 关键缺失(P0) / 重要遗漏(P1) / 建议补充(P2) |
| 证据支撑 | 为什么该标准必须引用 |
| 来源 | 国际 / 国内 / 院内 |
| 提出专家 | 评审人 |
