# R3-MDT链路审查报告

**评审日期**：2026-07-26  
**方法**：按MDT全链路（临床→影像→病理→药学→管理）审查每环节的标准引用完整性

---

## 链路一：肿瘤MDT链路

### 审查范围
- **临床端**：A18(肝癌), A24(结直肠癌), A38(膀胱癌), A42(前列腺), A43(前列腺), A48(胃肠肿瘤), A76(肿瘤), A82(化疗)
- **影像端**：A73(乳腺), A74(质控), A75(对比剂)
- **病理端**：A1(病理)
- **药学端**：A65(DrugAgent), A68(化疗管理)
- **管理端**：A71(围术期质控)

### 链路缺失发现

| 链路缺口 | 缺失标准 | 等级 |
|---------|---------|------|
| **临床→影像** | 肿瘤影像结构化报告标准 (LI-RADS/VI-RADS/NI-RADS 体系) | P0 |
| **临床→病理** | CAP 肿瘤病理报告方案 (跨瘤种) | P0 |
| **影像→病理** | 影像-病理对照验证标准 | P1 |
| **临床→药学** | 化疗方案审核标准 / ASCO止吐指南配对 | P1 |
| **药学→临床** | 药物基因组学(CPIC)与化疗方案选择的关联标准 | P1 |
| **全链路** | MDT会议质量标准 (如 Cancer MDT Quality Metrics) | P1 |
| **全链路** | 肿瘤分期多学科一致性校验标准 | P1 |

## 链路二：围手术期MDT链路

- **麻醉端**：(无独立麻醉科文档，零覆盖)
- **重症端**：A5(NICU), A80(神经重症营养)
- **护理端**：A20(护理)
- **药学端**：A67(营养), A69(止吐), A66(血友病围术期)
- **管理端**：A71(围术期质控)

### 链路缺失发现

| 链路缺口 | 缺失标准 | 等级 |
|---------|---------|------|
| **外科→麻醉** | **完全缺失麻醉科文档和麻醉标准** | **P0** |
| **外科→重症** | ICU转入/转出标准 (SOFA/qSOFA 等) 仅在A80部分覆盖 | P1 |
| **外科→护理** | ERAS多学科协作中护理的标准化路径 | P1 |
| **麻醉→药学** | 围术期抗菌药物预防使用指南(ASHP/IDSA) | P1 |
| **全链路** | **ERAS多学科实施标准** (ASER/ERAS Society 各手术路径) | P0 |
| **全链路** | 围术期疼痛管理MDT共识 | P1 |
| **全链路** | 围术期输血管理指南 (AABB/NICE) | P1 |
| **全链路** | 围术期血糖管理标准 | P1 |
