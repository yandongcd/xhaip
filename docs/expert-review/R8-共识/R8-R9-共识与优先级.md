# R8-矛盾消解与共识 + R9-优先级矩阵

**日期**：2026-07-26  
**参与**：44科室专家 + 3家模拟医院（协和/华西/中山）  
**累积输入**：R1-R7 共 555 项遗漏发现

---

## 一、跨轮次矛盾识别与消解

### 矛盾 #1：CSCO vs NCCN 版本对齐
- **R1 发现**：多份肿瘤文档引用 CSCO 2024
- **R4 发现**：NCCN 2025 已发布但文档引用 NCCN 版本不统一
- **R8 共识**：**统一要求引用 "CSCO 2024 + NCCN 2025"，版本号必须在文档中明确标注**

### 矛盾 #2：CLSI vs EUCAST 药敏标准
- **R1**：A79 引用了 CLSI
- **R5**：提出应补充 EUCAST
- **R8 共识**：**中国主要使用 CLSI，EUCAST 作为备选参考。保留 CLSI + 新增 EUCAST 作为"补充引用"**

### 矛盾 #3：BI-RADS 版本
- **R1**：A73 引用 BI-RADS v2025 (第6版)
- **R4**：建议明确超声/DBT/CE-MRI各扩展词典
- **R8 共识**：**BI-RADS 第6版为主体，各模态扩展词典单独列出**

### 矛盾 #4：AI注册 vs 临床研究标准 优先级
- **R6**：ISO 14971 / IEC 62304 标记为 P0
- **R7**：CONSORT-AI / SPIRIT-AI 也标记为 P0
- **R8 共识**：**ISO系列为法规级P0（不满足则不能上市），CONSORT-AI为学术级P0（不满足则无法发表）。分列两条P0体系**

### 矛盾 #5：泛称引用的接受度
- **R1**：批评30%文档使用"指南共识"泛称
- **R3**：部分MDT文档因跨专科，泛称可接受
- **R8 共识**：**"指南共识"泛称一律不可接受。每个文档必须至少引用3个具名(含版本号)的核心指南。跨专科MDT文档更应列出所有涉及科室的指南**

3. 40+ 份文档需将"泛称"指南替换为 ≥3 条具名指南
