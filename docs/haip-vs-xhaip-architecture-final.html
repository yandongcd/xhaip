维度HAIP-0710 v0.2.0xhaip v1.2

Agent 定义Python 子包 + DomainPlugin + ~620 行胶水。新增 Agent 修改 3 引擎文件。→30 行 YAML + 纯业务逻辑。A2A 路由/端口/工具注册全自动。

2. Gap 闭合矩阵 — 12→0

v1.2 补齐以前 xhaip 缺少的全部关键能力。以下是每项 Gap 的闭合状态。

  • S1 权限系统 (U2A/A2A/A2D) CLOSED
    0710 有完整 3-schema/14-table/OPA 权限体系。xhaip v1.1 为零。v1.2 实现 SQLite RBAC + A2A/A2D policy table + 桥接已有 auth/rbac + audit/AuditLogger。
  • S2 Audit 审计日志 CLOSED
    v1.2 实现 SQLite audit_access_log + audit_policy_change 表 + 接入已有 AuditLogger。A2A 调用自动记录。
  • S3 Guard 门控 CLOSED
    GuardVerifier 从"仅诊断"升级为"强制阻断"。guard_result.passed 为 False 时返回 status:blocked。移除非高危完全 bypass。
  • A1 Citation 强制 CLOSED
    YAML GuardConfig 新增 CitationConfig 块。支持 required/min_sources/min_trust 字段。Agent 可配置引用策略。
  • A2 版本依赖执行 CLOSED
    depends_on 已被 DomainPlugin 解析，v1.2 增加 _validate_depends() 运行时校验。版本不匹配时返回 VERSION_MISMATCH。
  • A3 T1/T2 信任门控 CLOSED
    citation.all_t1() 接入 GuardVerifier 高危场景检查。缺 T1 引用时 flag。无任何引用时 flag。
  • A4 Pre-LLM 路由 CLOSED
    新增 KeywordRouter (before_agent hook)。关键词匹配直接路由到 Agent，0 token 快速通道。
  • A5 Guard in AgentLoop CLOSED
    Guard 从 a2a.call_with_loop() 外部移入 AgentLoop.run() 内部。每 step 输出后 guard check。
  • B1 Transport 抽象 CLOSED
    新增 a2a/transport.py。AgentTransport ABC + InProcess/MCP/Mock 实现 + transport registry。
  • B2 HITL 集成 CLOSED
    新增 loop/hitl.py。HITLHook (after_agent hook)。低置信度或 guard block 时生成 HITLRequest 等待人工确认。
  • B3 Data Product 适配器 CLOSED
    新增 data/__init__.py。DataSourceAdapter ABC + SQLiteDataSource/MockDataSource + DataProductRegistry (11 products seeded)。
  • G1 权限桥接重复 CLOSED
    permission/ 模块桥接到已有 auth/rbac.has_permission() + audit/AuditLogger。删除重复的 _role_permissions dict。

6. 剩余 Gap — 仅 3 项 (全部为增强型)

以下为"有更好，没有也不影响 PROD 就绪"的增强项。

  • Rule Engine DSL 路径 DEFERRED
    0710 的 DSL evaluator + arbitration engine 刻意未移植。xhaip 选择 YAML static + LLM。双路径维护成本 > 收益。
  • 真实患者数据 FUTURE
    0710 有 9 例真实南方医院病例 (NF001-NF009)。需签署数据协议后才能引入。
  • 6 临床工作流空白 (急诊/ICU/MedRec/MDT/慢病/围术期) ROADMAP
    标注为 [FUTURE]。42 空壳 BP 已删除。留给专业临床团队建设。

  • Toposort 分层并行 vs 顺序执行
  • SQLite knowledge store vs YAML 直读
  • FastAPI + 20 endpoints vs http.server
  • FastMCP (SSE) + JSON-RPC fallback
  • 314 规则 (53组) vs 22 规则
  • 70 指南 (30+科室) vs 19 (髋部专精)
