# WS/T 312-2009 医院感染监测规范
# 来源: 国家卫生健康委员会 (2009)
# 状态: 摘要（从临床实践提取核心内容）

name: 医院感染监测规范
source: 国家卫生健康委员会
version: WS/T 312-2009
trust_level: T1
category: infection_control

key_content:
  scope: 适用于各级医疗机构的医院感染监测
  surveillance_types:
    - comprehensive_surveillance: 对全院所有住院患者和工作人员的医院感染及其相关危险因素进行全面监测
    - targeted_surveillance: 针对特定人群、特定部位、特定环节进行重点监测
  core_indicators:
    hospital_infection_rate: 医院感染发病率（同期新发感染例数/同期住院患者总数×100%）
    surgical_site_infection: SSI发生率（按手术切口等级分层）
    device_associated_infection:
      - CLABSI: 中心静脉导管相关血流感染（例/1000导管日）
      - CAUTI: 导尿管相关尿路感染（例/1000导管日）
      - VAP: 呼吸机相关肺炎（例/1000呼吸机日）
    mdro_rate: 多重耐药菌检出率（按菌种分层: MRSA/VRE/CRE/CRAB/CRPA）
  outbreak_definition:
    - 同一病区7天内≥3例同种同源病原体感染
    - 特殊耐药菌(CRE)单例即需关注
  reporting:
    - 医院感染病例24h内上报
    - 医院感染暴发2h内电话报告+12h内书面报告至卫生行政部门
  methods:
    - 前瞻性监测(每日查房+微生物报告追踪)
    - 回顾性监测(出院病历回顾)
    - 目标性监测(ICU/手术室/NICU)
